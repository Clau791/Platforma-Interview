# Roadmap

## Phase 1 - Core infrastructure
- Project scaffolding (frontend, backend, DB).
- Auth + profile.
- Basic session CRUD.

## Phase 2 - Voice-first arena
- Audio capture/playback in frontend.
- STT -> LLM -> TTS pipeline in backend.
- Latency instrumentation.

## Phase 3 - Vision and emotion
- Snapshot upload flow.
- Emotion detection pipeline.
- LLM context adaptation.

## Phase 4 - Code sandbox
- Monaco editor integration.
- Docker execution service.
- LLM technical evaluation.

## Phase 5 - Coach report
- Report generator and JSON schema.
- Visualization of emotion timeline.
- Export/share.
